## Русский

Версия 1.2 закрывает обещанное и убирает боль повторного чтения. Плюс
появились тесты и проверка при сборке — после того, как в 1.1 я выкатил
сломанный CSS и не заметил.

### Как начать

Скачайте **`memoroid-single.html`**, откройте двойным щелчком, нажмите
«Открыть файл». Без установки и интернета.

```
SHA-256: 063732d93e36dc885b625beae253e3df654dc10c93c3d69b94935cb006e7322d
```

### Что нового

**Доделано обещанное**

- **Печать и PDF.** `@media print` скрывает сайдбар, шапку, тулбар и меню —
  на бумагу уходит только документ с подписью: имя файла, дата, число слов,
  «Напечатано из Memoroid». Шорткат `⌘P`.
- **Удаление подключённой папки.** Новый раздел «Подключённые папки» в
  библиотеке: имя, число файлов, кнопка «Удалить» с подтверждением. Удаляется
  только запись каталога — файлы на диске, черновики, избранное и недавние
  не затрагиваются.
- **Настраиваемые исключения.** Встроенный список расширен (`.svn`, `.hg`,
  `.idea`, `.vscode`, `.venv`, `.tox`, `.ssh`, `.aws`, `vendor` и др.), плюс
  поле «Исключить папки» в меню «Ещё».

**Боль повторного чтения**

- **Позиция чтения** запоминается в рамках сессии и восстанавливается при
  возврате к документу. Между перезапусками не сохраняется — заметка,
  открытая через неделю, начинается сверху.
- **Горячие клавиши:** `⌘O` открыть, `⌘P` печать, `⌘E` правка, `⌘S` сохранить,
  `/` поиск, `Esc` закрыть. В fallback-режиме `⌘S` честно говорит, что запись
  недоступна, и скачивает копию.
- **Исправлен `/`:** раньше он перехватывал фокус даже когда вы печатали слэш
  в поле тегов или в поиске библиотеки.

**Инфраструктура**

- **41 тест** на чистую логику: рендер списков и таблиц, даты, front matter,
  задачи, обход папок, исключения, позиция чтения. Запуск: `node --test "tests/*.test.js"`.
- **Сборка проверяет синтаксис** (`node --check`) и наличие внешних ассетов,
  а `-Help` печатает справку.

### Ограничения

- Подключение папок и запись в файл — только в браузерах с File System Access
  API (Chrome, Edge). В Firefox, Safari и на мобильных работает
  fallback-режим: чтение и черновики, сохранение даёт копию.
- Ни одного сетевого запроса, никакой телеметрии.

Подробности в [README](https://github.com/xodapi/memoroid#memoroid).

## English

Version 1.2 completes what was promised and removes the friction of re-reading
a note. It also adds tests and a build-time check — after shipping broken CSS
in 1.1 without noticing.

### Getting started

Download **`memoroid-single.html`**, double-click it, click «Open file». No
install, no internet.

```
SHA-256: 063732d93e36dc885b625beae253e3df654dc10c93c3d69b94935cb006e7322d
```

### What's new

**Promised work completed**

- **Print and PDF.** `@media print` hides the sidebar, topbar, toolbar and
  menu — only the document and a footer caption reach paper: filename, date,
  word count, «Printed from Memoroid». Shortcut `⌘P`.
- **Removing a connected folder.** A new «Connected folders» section in the
  library: name, file count, and a «Remove» button with confirmation. Only
  the catalog entry is removed — files on disk, drafts, favorites and recent
  documents are untouched.
- **Configurable excludes.** The built-in list is expanded (`.svn`, `.hg`,
  `.idea`, `.vscode`, `.venv`, `.tox`, `.ssh`, `.aws`, `vendor`, and more),
  plus an «Exclude folders» field in the «More» menu.

**Friction of re-reading**

- **Reading position** is remembered for the session and restored when you
  return to a document. It is deliberately not persisted: a note opened a week
  later still starts at the top.
- **Shortcuts:** `⌘O` open, `⌘P` print, `⌘E` edit, `⌘S` save, `/` search,
  `Esc` dismiss. In fallback mode `⌘S` says plainly that writing is
  unavailable and downloads a copy.
- **Fixed `/`:** it used to steal focus even while you were typing a slash
  into the tags field or the library search.

**Infrastructure**

- **41 tests** over pure logic: list and table rendering, dates, front matter,
  tasks, folder walking, excludes, reading position. Run with
  `node --test "tests/*.test.js"`.
- **The build validates syntax** (`node --check`) and rejects any surviving
  external asset; `-Help` prints usage.

### Limitations

- Folder connection and writing to the original file require a browser with
  the File System Access API (Chrome, Edge). In Firefox, Safari, and on mobile
  the app runs in fallback mode: reading and drafts work, saving produces a
  copy.
- No network requests, no telemetry.

Details in the [README](https://github.com/xodapi/memoroid#memoroid).
