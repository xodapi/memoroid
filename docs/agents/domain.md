# Domain documentation

This is a single-context project.

Before changing the project, read:

- `CONTEXT.md`
- relevant files in `docs/adr/`

Use the vocabulary defined in `CONTEXT.md`. Add a term when the project
acquires a concept that is important to its behavior or boundaries.

Use an ADR for a decision that is hard to reverse, surprising without context,
and the result of a meaningful trade-off.

`CONTEXT.md` is a glossary, not an implementation specification.
