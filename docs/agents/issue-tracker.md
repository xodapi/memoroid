# Issue tracker: Local Markdown

Issues and specifications for this repository live as Markdown files in
`.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The specification is `.scratch/<feature-slug>/spec.md`
- Implementation tickets are `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Ticket numbering starts at `01`; do not combine tickets into one file.
- Triage state is recorded with a `Status:` line near the top.
- Discussion is appended under `## Comments`.

When a skill says to publish an issue, create the relevant Markdown files
inside `.scratch/`.
