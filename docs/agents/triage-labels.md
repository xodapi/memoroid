# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer must evaluate the issue |
| Needs information | `needs-info` | More information is required |
| Ready for agent | `ready-for-agent` | Fully specified for agent work |
| Ready for human | `ready-for-human` | Requires a human decision or action |
| Won't fix | `wontfix` | The issue will not be actioned |
